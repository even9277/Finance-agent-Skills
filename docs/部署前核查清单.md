# 部署前核查清单（WSL / Linux）

在运行主程序前，可在项目根目录执行以下命令，确认关键文件与目录完整。将 `{项目根目录}` 替换为你的实际路径（如 `/root/Finance`）。

```bash
cd {项目根目录}

# 关键文件
test -f requirements.txt && echo "OK: requirements.txt" || echo "MISSING: requirements.txt"
test -f Financial-MCP-Agent/.env.example && echo "OK: .env.example" || echo "MISSING: .env.example"
test -f Financial-MCP-Agent/.env && echo "OK: .env (已创建)" || echo "未创建: 请 cp Financial-MCP-Agent/.env.example Financial-MCP-Agent/.env"
test -f Financial-MCP-Agent/src/main.py && echo "OK: main.py" || echo "MISSING: main.py"
test -f Financial-MCP-Agent/src/tools/mcp_config.py && echo "OK: mcp_config.py" || echo "MISSING: mcp_config.py"
test -f a-share-mcp-is-just-i-need/pyproject.toml && echo "OK: a-share pyproject.toml" || echo "MISSING: a-share pyproject.toml"
test -f a-share-mcp-is-just-i-need/mcp_server.py && echo "OK: mcp_server.py" || echo "MISSING: mcp_server.py"
test -d a-share-mcp-is-just-i-need/src && echo "OK: a-share src" || echo "MISSING: a-share src"
```

全部输出 `OK` 且已创建 `.env` 后，再确认：

1. **.env** 中已填写 `OPENAI_COMPATIBLE_API_KEY`、`OPENAI_COMPATIBLE_BASE_URL`、`OPENAI_COMPATIBLE_MODEL`，且 `USE_LOCAL_MODEL=api`。
2. **mcp_config.py** 中 `--directory` 已改为 a-share-mcp-is-just-i-need 的**绝对路径**。
3. 已激活虚拟环境（`source .venv/bin/activate`）并设置 `export PYTHONPATH="${PWD}"`。

详见 **《部署指南-智星云-WSL-uv.md》** 步骤 6。
