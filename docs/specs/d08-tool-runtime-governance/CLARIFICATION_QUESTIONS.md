# D08 澄清结论

## 用户已确认

- 允许且必须执行受保护真实 API 测试，模拟真实使用。
- 不修改面试/项目描述文档，只开发代码与必要测试。
- D07、D10 不做；D08、D09按推荐方向开发。
- D09 迁移完成删除旧 Resolver，不保留长期双轨。

## D08 采用的保守默认

- 首期只接入受控对话，报告模式不接入。
- 全局并发保持现有默认 4，并允许 `RunBudget` 覆盖；不为文档数字强制改为 6。
- 工具级熔断、API family 级限流；未知工具继续由现有目录 fail-closed。
- timeout/429/短暂 5xx 计入瞬时失败；参数和永久 4xx 不重试、不计入瞬时失败率。
- Redis 故障退回保守本地状态，健康标记 DEGRADED。
- Discovery 健康仅作快照；执行前重新检查。
- Live 测试只读、显式 marker/env gate、禁止整轮自动重试和敏感 artifact。

## 延后

- 报告 Agent 工具权限和报告运行时治理。
- 动态按供应商套餐自动发现配额。
- API Gateway 用户级限流、分布式队列和通用治理平台。
