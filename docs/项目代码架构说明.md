# Finance 项目代码架构说明

> 本文档面向完全不了解本项目的读者，用于快速了解每个文件夹的代码内容与功能，便于上手与二次开发。

---

## 一、项目总览

本项目是一个**金融分析 + 量化交易**的综合系统，主要包含三块能力：

| 能力 | 说明 | 对应模块 |
|------|------|----------|
| **A 股智能分析报告** | 用户用自然语言提问（如「帮我看看茅台(600519)值得投资吗」），系统自动调用多个 AI 分析师（基本面、技术面、估值、新闻）并生成 Markdown 报告 | `Financial-MCP-Agent` + `a-share-mcp-is-just-i-need` |
| **新闻情感/风险模型** | 用 Qwen 等大模型 + LoRA 微调，得到「情感分析」和「风险评估」两个小模型，供新闻分析使用 | 根目录 `train_qwen_*.py`、`test_*.py` 等 |
| **美股强化学习交易** | 基于 FinRL，用 PPO/CPPO 等算法训练交易智能体，可接入 LLM 情感/风险信号（DeepSeek 等） | `FinRL_DeepSeek` |

**数据流关系简述：**

- **A 股分析**：用户 → `Financial-MCP-Agent`（多 Agent 工作流）→ 通过 MCP 调用 `a-share-mcp-is-just-i-need` 获取 A 股数据（Baostock）和新闻爬虫；新闻爬虫内部可调用根目录训练好的**情感/风险模型**。
- **美股交易**：历史行情 + 新闻情感/风险数据 → `FinRL_DeepSeek` 的数据脚本 → 训练环境与 PPO/CPPO 训练脚本 → 交易智能体。

下面按**目录**逐块说明每个文件夹的作用和主要文件。

---

## 二、根目录（/Finance）

项目根目录下既有「数据与模型脚本」，也有「入口说明」，一般不直接作为服务运行，而是被其他模块或命令行调用。

### 2.1 文档与配置

| 文件 | 作用 |
|------|------|
| **README.md** | 一键上手指南：Autodl GPU 创建、Cursor SSH 远程开发、依赖安装、MCP 配置、模型下载/训练、测试与常见问题。 |
| **安装.md** | 精简版安装与运行步骤：依赖、API/FinR1 配置、MCP 路径、情感/风险模型训练、MCP 与 Agent 测试。 |
| **requirements.txt** | Python 依赖（如 langgraph、langchain-openai、peft、transformers、baostock、uv 等）。 |
| **package.json** | 当前主要用来说明项目，依赖里有 `@anthropic-ai/claude-code`，与核心 Python 流程无强绑定。 |

### 2.2 数据与模型相关脚本

| 文件 | 功能说明 |
|------|----------|
| **download.py** | 使用 `huggingface_hub.snapshot_download` 下载 **Qwen3-8B** 到本地（如 `./Qwen`），供后续 LoRA 微调使用。 |
| **data_process.py** | **新闻去重与预处理**：`NewsDeduplicator` 类，包含标题/正文相似度（编辑距离、TF-IDF、SimHash 等）、去重逻辑，为训练或分析准备干净新闻文本。 |
| **train_qwen_risk.py** | 使用 **Qwen + LoRA** 在风险标注数据上微调，得到**风险分析模型**（输出 1–5 分）。数据需包含 `Lsa_summary`、`risk_deepseek` 等字段。 |
| **train_qwen_sentiment.py** | 使用 **Qwen + LoRA** 在情感标注数据上微调，得到**情感分析模型**（1–5 分）。 |
| **test_risk_model.py** | 加载训练好的**风险模型**（默认路径如 `qwen_risk_model` + 基座 `Qwen`），对给定新闻做风险评估测试。 |
| **test_qwen_sentiment.py** | 加载训练好的**情感模型**，对给定新闻做情感分析测试。 |

**小结**：根目录负责「**数据下载、数据清洗、风险/情感模型训练与测试**」。训练出的模型路径需在 `a-share-mcp-is-just-i-need` 的 `baostock_data_source.py` 中配置，供新闻爬虫的情感/风险分析使用。

### 2.3 数据目录（示例/结果）

| 目录/文件 | 说明 |
|-----------|------|
| **risk_nasdaq/**、**risk_nasdaq_news/** | 与美股风险标注、新闻相关的数据或处理结果（如 `risk_llama_cleaned_nasdaq_news_full.csv` 等），多用于 FinRL_DeepSeek 或数据预处理。 |
| **nasdaq_news_sentiment/** | 纳斯达克新闻情感相关数据（如 `1.csv`、`1.ipynb`），与情感模型数据集或实验相关。 |

这些目录多为数据与 notebook，不是「可运行服务」，而是为训练和回测提供数据来源。

## 三、Financial-MCP-Agent（金融分析多智能体）

这是**面向用户的 A 股分析入口**：用自然语言问股票问题，系统通过多个专业 Agent 并行分析，最后汇总成一份报告。

### 3.1 整体流程

- **入口**：`src/main.py`（支持 `--command "..."` 或交互式输入）。
- **工作流**：使用 **LangGraph** 的 `StateGraph(AgentState)`：
  - 起点：`start_node`
  - 四个分析节点**并行**：`fundamental_analyst`、`technical_analyst`、`value_analyst`、`news_analyst`
  - 汇总节点：`summarizer`
  - 边：start → 四个 analyst → summarizer → END
- **状态**：`AgentState`（在 `src/utils/state_definition.py`）包含 `messages`、`data`、`metadata`；各 Agent 读写共享的 `data`（如股票代码、公司名、各模块分析结果）。

### 3.2 目录与主要文件

```
Financial-MCP-Agent/
├── src/
│   ├── main.py                 # 主入口：解析命令行/交互输入、提取股票信息、构建并运行 LangGraph 工作流、写报告
│   ├── agents/                 # 五个 Agent 实现
│   │   ├── fundamental_agent.py  # 基本面分析（财务、盈利、运营等）
│   │   ├── technical_agent.py    # 技术分析（K 线、指标、趋势）
│   │   ├── value_agent.py        # 估值分析（PE、PB 等）
│   │   ├── news_agent.py         # 新闻分析（情感 + 风险，依赖 MCP 工具）
│   │   └── summary_agent.py      # 汇总各 Agent 结果，生成最终 Markdown 报告（可接本地 FinR1）
│   ├── tools/
│   │   ├── mcp_config.py        # MCP 服务器配置（如 a_share_mcp_v2 的 command/args，含 a-share 项目路径）
│   │   ├── mcp_client.py        # 通过 MCP 获取「工具列表」供 Agent 调用（get_mcp_tools）
│   │   └── openrouter_config.py # 若使用 OpenRouter 等 API 的配置
│   └── utils/
│       ├── state_definition.py   # AgentState 及 merge 规则
│       ├── logging_config.py     # 日志配置
│       ├── execution_logger.py   # 单次执行的日志（按会话目录记录）
│       ├── llm_clients.py        # LLM 客户端封装
│       └── ...
├── reports/                    # 生成的 Markdown 报告输出目录
├── logs/                       # 执行日志（含各 Agent 的交互记录）
├── test_extraction.py          # 测试从自然语言中抽取股票代码/公司名
└── .env.example / .env         # API Key、Base URL、Model、USE_LOCAL_MODEL 等
```

### 3.3 各 Agent 简要说明

- **fundamental_agent / technical_agent / value_agent / news_agent**：均使用 **ReAct**（`create_react_agent`），从 `state["data"]` 取 query、stock_code、company_name，然后通过 **MCP 客户端**拿到 A 股工具（来自 `a-share-mcp-is-just-i-need`），按需调用 K 线、财务、宏观、新闻等接口，把分析结果写回 `state["data"]`。
- **summary_agent**：读取前四个 Agent 写入的 `data`，整合成一份最终报告；可配置为使用**本地 FinR1** 或 API 模型，并负责写文件到 `reports/`。

**小白记忆要点**：  
- 要跑通「问一句话得报告」，需要：正确配置 `.env`、在 `mcp_config.py` 里填好 `a-share-mcp-is-just-i-need` 的路径。  
- 报告在 `reports/`，单次运行日志在 `logs/` 下按时间戳的目录里。

## 四、a-share-mcp-is-just-i-need（A 股 MCP 数据服务）

这是**面向 A 股的 MCP 服务器**：对外暴露「获取 K 线、财务、指数、宏观、新闻爬虫」等工具，供 `Financial-MCP-Agent` 中的 Agent 通过 MCP 协议调用。

### 4.1 运行方式

- **入口**：`mcp_server.py`。
- **协议**：FastMCP，`transport='stdio'`，由 Cursor/Claude 或本项目的 MCP 客户端按配置拉起（如 `uv run --directory <路径> python mcp_server.py`）。

### 4.2 目录与主要文件

```
a-share-mcp-is-just-i-need/
├── mcp_server.py              # 入口：创建 FastMCP app，注入 Baostock 数据源，注册各模块工具
├── src/
│   ├── data_source_interface.py  # 抽象接口 FinancialDataSource（如 get_historical_k_data、get_profit_data 等）
│   ├── baostock_data_source.py   # 基于 Baostock 的实现：K 线、财务、指数、宏观、新闻爬虫；新闻爬虫内可调「风险/情感」模型
│   ├── utils.py                  # 通用工具（如 baostock 登录上下文、数据获取封装）
│   ├── formatting/
│   │   └── markdown_formatter.py # 将 DataFrame 转为 Markdown 表格
│   └── tools/                    # 按功能拆分的工具注册
│       ├── stock_market.py       # 股票 K 线、基本信息等 → register_stock_market_tools
│       ├── financial_reports.py # 财报相关（利润、运营、成长、资产负债表等）→ register_financial_report_tools
│       ├── indices.py            # 指数成分股（如沪深300、中证500）→ register_index_tools
│       ├── market_overview.py    # 市场概览类 → register_market_overview_tools
│       ├── macroeconomic.py     # 宏观（存贷款利率、准备金率等）→ register_macroeconomic_tools
│       ├── date_utils.py        # 交易日、时间范围等 → register_date_utils_tools
│       ├── analysis.py          # 综合分析类工具 → register_analysis_tools
│       └── news_crawler.py      # 新闻爬虫（搜新闻、爬正文、调用风险/情感模型）→ register_news_crawler_tools
└── test_baostock.py            # 测试 Baostock 连接与基本数据接口
```

### 4.3 数据源与新闻中的模型

- **BaostockDataSource** 实现 `FinancialDataSource`，所有「行情、财务、指数、宏观」都走 Baostock。
- **新闻爬虫**（在 `baostock_data_source.py`）：根据公司/行业关键词做网页搜索并爬取正文，然后可调用：
  - **风险模型**：`_load_risk_model`、`_analyze_risk`（路径在代码中配置，如 `qwen_risk_model` + 基座 `Qwen`）。
  - **情感模型**：`_load_sentiment_model`、`_analyze_sentiment`。
- 若无 GPU 或暂不训练，可在 `baostock_data_source.py` 中注释掉与风险/情感相关的调用，仅保留爬虫与摘要。

**小白记忆要点**：  
- 这里是「**数据与工具**」层；真正和用户对话的是 `Financial-MCP-Agent`。  
- 修改 MCP 路径时，改的是 `Financial-MCP-Agent/src/tools/mcp_config.py` 里指向本目录的 `--directory`。  
- 风险/情感模型路径在 `baostock_data_source.py` 的 `_load_risk_model` / `_load_sentiment_model` 中修改。

## 五、FinRL_DeepSeek（美股强化学习交易）

这是**独立于 A 股分析**的一块：用强化学习（PPO、CPPO 等）在美股历史数据上训练交易智能体，可选接入 LLM 情感/风险信号（如 DeepSeek 标注的数据）。

### 5.1 整体逻辑

- **环境**：Gymnasium 风格的 `StockTradingEnv`，状态包含持仓、现金、技术指标等，动作多为连续（买卖比例）。
- **算法**：PPO（无 LLM）、CPPO（风险约束）、PPO-LLM（带情感/风险等特征）、CPPO-LLM 等，对应不同 `train_*.py` 和 `env_stocktrading*.py`。
- **数据**：先有行情数据（如 HuggingFace 上的 nasdaq 数据），再通过 `sentiment_deepseek_deepinfra.py` / `risk_deepseek_deepinfra.py` 为新闻打情感/风险标签，再用 `train_trade_data*.py` 生成带这些特征的训练用数据。

### 5.2 目录与主要文件

```
FinRL_DeepSeek/
├── env_stocktrading.py              # 基础交易环境（无 LLM 特征）
├── env_stocktrading_llm.py           # 带 LLM 情感/风险等特征的环境（PPO-DeepSeek 用）
├── env_stocktrading_llm_01.py        # 同上，另一套参数/特征设计
├── env_stocktrading_llm_risk.py     # CPPO-DeepSeek 用环境（风险敏感）
├── env_stocktrading_llm_risk_01.py
├── env_stocktrading_llama.py         # 使用 Llama 相关信号的环境
├── env_stocktrading_llama_risk.py
├── train_ppo.py                     # 标准 PPO 训练
├── train_cppo.py                    # CPPO 训练
├── train_ppo_llm.py                 # PPO + LLM 信号
├── train_ppo_llama.py
├── train_cppo_llm_risk.py           # CPPO + LLM 风险信号
├── train_cppo_llm_risk_01.py
├── train_cppo_llama_risk.py
├── train_trade_data.py               # 将行情转为训练用数据（无 LLM）
├── train_trade_data_deepseek_sentiment.py  # 带 DeepSeek 情感的数据
├── train_trade_data_deepseek_risk.py
├── train_trade_data_llama_risk.py
├── train_trade_data_qwen_risk.py
├── sentiment_deepseek_deepinfra.py  # 用 DeepSeek/DeepInfra 为新闻打情感标签
├── risk_deepseek_deepinfra.py       # 打风险标签
├── hugging_face_upload.py            # 上传数据/模型到 HuggingFace
├── FinRL_DeepSeek_backtesting.ipynb # 回测与评估（如 Information Ratio、CVaR）
├── installation_script.sh           # 依赖安装脚本
├── README.md                        # 数据、训练命令、环境与评估说明
└── output_*.log                     # 训练日志（如 output_ppo.log）
```

### 5.3 使用顺序（理解用）

1. 准备行情与新闻数据（见 README 中的 HuggingFace 链接）。
2. 可选：运行 `sentiment_deepseek_deepinfra.py`、`risk_deepseek_deepinfra.py` 得到带情感/风险的数据集。
3. 运行对应的 `train_trade_data*.py` 生成环境所需的输入数据。
4. 根据算法选择对应 `env_stocktrading*.py`，运行 `train_ppo.py` / `train_cppo.py` / `train_ppo_llm.py` / `train_cppo_llm_risk.py` 等（README 中有示例命令，如多进程 `mpirun`）。
5. 用 `FinRL_DeepSeek_backtesting.ipynb` 做回测与指标评估。

**小白记忆要点**：  
- 这一块是**美股 + 强化学习**，和前面的「A 股问答 + MCP」是两套系统，但情感/风险的数据思路与根目录的 Qwen 微调有联系（例如都涉及新闻情感与风险标注）。  
- 想跑训练先看 `FinRL_DeepSeek/README.md` 和 `installation_script.sh`。
