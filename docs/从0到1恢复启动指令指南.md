## 从 0 到 1 恢复启动指令指南（重启主机后）

> **适用场景**：你租用的 Linux 实例重启/更换后，需要把本项目的 **PostgreSQL + pgAdmin + 后端 + 前端**完整拉起，继续开发。  
> **默认端口**：Postgres `5432`、pgAdmin `5050`、后端 `8000`、前端（开发）`5173`

---

### 0. 进入项目目录（所有命令默认从这里开始）

```bash
cd /root/Finance
```

---

### 1. 启动 PostgreSQL + pgAdmin（Docker Compose）

#### 1.1 检查 Docker

```bash
docker --version
docker compose version
```

#### 1.2 启动容器

```bash
cd /root/Finance/docker
docker compose up -d postgres pgadmin
```

#### 1.3 查看运行状态（应看到 healthy）

```bash
docker compose ps
```

#### 1.4 验证数据库可连接

```bash
docker exec -i finance_postgres psql -U finance -d finance_db -c "SELECT version();"
```

#### 1.5 验证 pgvector 扩展（首次初始化数据目录会自动建；不确定就查一下）

```bash
docker exec -i finance_postgres psql -U finance -d finance_db -c "SELECT extname, extversion FROM pg_extension WHERE extname IN ('vector','uuid-ossp') ORDER BY extname;"
```

---

### 2. pgAdmin 访问与注册数据库

#### 2.1 打开地址

- **pgAdmin Web**：`http://<你的服务器IP>:5050`

#### 2.2 默认登录账号（来自 `docker/docker-compose.yml`）

- **Email**：`admin@local.com`
- **Password**：`admin123456`

#### 2.3 注册服务器（Register → Server）

- **Name**：随意（如 `finance_postgres`）
- **Connection / Host name**：如果你用的是 Docker compose 网络，填 `postgres`；如果在本机直连也可填 `127.0.0.1`
- **Port**：`5432`
- **Maintenance database**：`finance_db`
- **Username**：`finance`
- **Password**：`finance123`

> 如果你填 `127.0.0.1` 连接失败，通常是因为 pgAdmin 容器里的 `127.0.0.1` 指向它自己。优先用 `postgres`。

---

### 3. 数据库结构快速自检（可选但推荐）

```bash
docker exec -i finance_postgres psql -U finance -d finance_db -c "\dt"
```

你应能看到（至少）这些表：
- `users`
- `sessions`
- `messages`
- `session_summaries`
- `user_invest_profiles`
- `ltm_write_tasks`

#### 3.1（仅一次）STM 摘要快照补列（如果你换了新库/新盘导致表没补齐）

```bash
docker exec -i finance_postgres psql -U finance -d finance_db -c \"ALTER TABLE session_summaries \
  ADD COLUMN IF NOT EXISTS compressed_user_count INTEGER DEFAULT 0, \
  ADD COLUMN IF NOT EXISTS compressed_assistant_count INTEGER DEFAULT 0, \
  ADD COLUMN IF NOT EXISTS start_message_id INTEGER, \
  ADD COLUMN IF NOT EXISTS end_message_id INTEGER, \
  ADD COLUMN IF NOT EXISTS start_created_at TIMESTAMP, \
  ADD COLUMN IF NOT EXISTS end_created_at TIMESTAMP;\" 
```

---

### 4. 后端（FastAPI）从 0 启动（宿主机开发模式）

#### 4.1 进入后端目录

```bash
cd /root/Finance
```

#### 4.2 确认 `.env`（关键：数据库与 Mem0 embedding 模型）

查看 `backend/.env` 是否至少包含：

- `ENABLE_STM=true`
- `ENABLE_MEMORY=true`
- `DATABASE_URL=postgresql+asyncpg://finance:finance123@localhost:5432/finance_db`
- `PG_HOST/PG_PORT/PG_DB/PG_USER/PG_PASSWORD`
- `MEM0_EMBED_MODEL=text-embedding-v2`

（Mem0 embedding 模型必须是 embedding 模型，不能用聊天模型；DashScope compatible-mode 推荐 `text-embedding-v2`）

#### 4.3 创建/激活虚拟环境

如果你已有 `.venv`，直接激活：

```bash
source /root/Finance/.venv/bin/activate
```

如果没有（第一次或你清理过环境）：

```bash
python3 -m venv /root/Finance/.venv
source /root/Finance/.venv/bin/activate
pip install -r /root/Finance/backend/requirements.txt
```

#### 4.4 启动后端（热重载）

```bash
cd /root/Finance
uvicorn backend.main:app --reload --port 8000
```

#### 4.5 健康检查

```bash
curl -s http://127.0.0.1:8000/api/health
```

### 5. 前端（Vue3）启动（开发模式）

```bash
cd /root/Finance/frontend
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

浏览器访问：
- `http://<你的服务器IP>:5173`

---

### 6. 一键启动（可选：全部容器化）

如果你想把后端/前端也用 docker compose 跑（生产构建方式）：

```bash
cd /root/Finance/docker
docker compose up -d postgres pgadmin backend frontend
docker compose ps
```

访问：
- 后端：`http://<你的服务器IP>:8000/api/health`
- 前端（容器版）：`http://<你的服务器IP>:5173`（容器内映射到 80）
- pgAdmin：`http://<你的服务器IP>:5050`

---

### 7. 常见问题快速排查

#### 7.1 只看到 Memory Items “入队”但 Mem0 不出条目

优先看后端启动日志里是否有：
- `config preview: llm_model=..., embed_model=text-embedding-v2, pg=...`

再看 outbox 队列：

```bash
docker exec -i finance_postgres psql -U finance -d finance_db -c "SELECT status, task_type, COUNT(*) FROM ltm_write_tasks GROUP BY status, task_type ORDER BY status, task_type;"
```

#### 7.2 pgAdmin 页面打不开

- `5050` 是 pgAdmin Web 端口，不是 `5432`  
  - Postgres：`5432`
  - pgAdmin：`5050`

#### 7.3 端口冲突

检查占用：

```bash
ss -lntp | grep -E ':(5432|5050|8000|5173)\\b' || true
```

---

### 8. 建议的“重启后顺序”（最省心）

- **先**：`docker compose up -d postgres pgadmin`
- **再**：启动后端（确保 `.env` 正确）
- **最后**：启动前端
