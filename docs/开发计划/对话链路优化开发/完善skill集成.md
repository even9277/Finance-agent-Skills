## 先回答你：这些事放在哪个阶段做？

### 推荐阶段归类（按优先级）

## Phase B（第二阶段）  
**工具链可靠性 + 工具注册治理**（1-2周）

- 目的：解决你说的“僵硬”和“该 web 不 web、该静态反而查实时”。

> 这个阶段放后面是因为它建立在前面可观测和工具稳定之上。
