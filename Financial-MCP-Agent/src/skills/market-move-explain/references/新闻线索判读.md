# 新闻线索判读

## 目的

这份参考只服务于 `market-move-explain`。
当 skill 已经拿到 Tushare 行情、指数、板块或 ETF 证据后，可以再用网页搜索去补“最近的消息催化线索”，但不能把网页结果直接当成已确认原因。

## 什么时候值得查网页

- 用户问题本身就带有“为什么涨/为什么跌/为什么异动/为什么拉升/为什么跳水”
- 行情或板块联动已经成立，但还缺少外部事件线索
- 用户明确追问“有没有公告/消息面原因”

## 优先保留的来源

- 主流财经媒体
- 交易所、上市公司公告页
- 券商/研究机构的公开摘要页

## 需要丢弃的来源

- 域名可疑、标题党、内容高度重复的 SEO 页面
- 没有具体对象、时间、事件指向的泛化摘要
- 与当前标的或板块明显不匹配的搜索结果

## 在回答里怎么用

- 可以写“搜索结果显示，近期存在以下线索”
- 可以写“这可能是盘面异动的补充催化”
- 不能写“确认原因就是某条新闻”
- 如果网页线索和盘面不一致，要明确写“消息面暂未形成可靠交叉验证”
