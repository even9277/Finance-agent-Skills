# 数据与消息交叉验证

1. 先确认对象类型和盘面是否存在实质异动。
2. 再检查网页线索与对象、主题和时间窗口是否一致。
3. 只有市场强证据时，只做数据侧解释。
4. 强证据与网页线索互相支持时，可做保守原因解释。
5. 只有网页线索时，必须说明缺少市场事实支撑。
