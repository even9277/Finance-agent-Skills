# 数据与消息交叉验证

## 核心原则

`market-move-explain` 是一个“先数据、后线索”的 skill。
Tushare 提供的是确定性市场证据，网页搜索提供的是补充线索。
最终回答必须先站在市场数据上，再决定是否引用搜索结果。

## 交叉验证顺序

1. 先确认对象是不是对的：个股、ETF、指数、板块有没有解析清楚
2. 再确认盘面是不是有实质异动：涨跌幅、成交活跃度、板块联动是否成立
3. 然后才看网页线索是否与当前对象和时间窗口一致
4. 只有“对象一致 + 时间接近 + 主题相符”时，网页线索才允许进入“可能驱动”

## 三种回答层级

- 只有 Tushare 证据：
  - 只能做数据侧解释
- Tushare 证据 + 网页线索一致：
  - 可以做保守的原因解释
- 只有网页线索：
  - 不能下确认性结论，只能提示证据不足

## 输出约束

- 已确认事实和可能驱动必须分开写
- 数据来源和网页来源都要留痕
- 若证据不足，优先保守，不强行归因
