# 板块简报口径

## 板块与指数口径

- 板块快照优先代表行业或主题整体表现，指数行情只能作为近似上下文。
- 如果只有指数数据，要明确“按指数口径观察”，不要冒充完整板块数据。
- 行业、概念、主题可能口径不同，输出时要说明采用的观察口径。

## 龙头判断

- 龙头或代表标的必须来自成分股、涨跌贡献、成交活跃度或市场关注度证据。
- 不要只凭模型常识指定龙头。
- 如果只有板块快照没有成分股，只能说“暂不展开代表标的判断”。

## 追高风险

- 对“还能不能追”这类问题，必须提示短线拥挤、回撤、轮动和消息兑现风险。
- 可以建议关注回调、量能持续性和板块内部扩散情况，但不要承诺继续上涨。
