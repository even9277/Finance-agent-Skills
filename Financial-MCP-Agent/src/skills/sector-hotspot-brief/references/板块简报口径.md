# 板块简报口径

- 板块快照优先表示行业或主题整体表现；指数行情只能作为近似上下文。
- 龙头或代表标的必须来自成分、涨跌贡献或成交活跃证据，不能凭模型常识指定。
- 只有指数数据时明确按指数口径观察；只有板块快照时不展开龙头判断。
- 对追高问题必须提示拥挤、回撤、轮动和消息兑现风险。
