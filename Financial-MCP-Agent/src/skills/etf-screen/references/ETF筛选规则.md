# ETF 筛选规则

- 先按主题、指数、行业或资产类别匹配，再按规模、流动性、跟踪质量和风险约束收敛。
- 近期表现只作辅助证据，不能单独决定 shortlist。
- shortlist 通常保留 2 到 3 只，并说明候选进入与排除原因。
- 证据不足时只给“可继续研究候选”，不输出强推荐。
