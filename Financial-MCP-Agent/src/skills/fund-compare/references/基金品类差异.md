# 基金品类差异

## ETF 与联接基金

- ETF 通常在场内交易，重点观察成交、折溢价、规模和跟踪标的。
- 联接基金通常投资对应 ETF，净值确认与交易效率不同，不能直接套用场内流动性指标。

## LOF、QDII 与跨类边界

- LOF 需要说明使用净值还是场内交易口径。
- QDII 受海外交易日、汇率和净值披露滞后影响，不宜与境内宽基直接比较短期表现。
- 跨资产、跨市场产品只比较配置属性和适配人群，不输出强收益排序。
