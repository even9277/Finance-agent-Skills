# 基金对比的可比性规则

- 优先对比同类型、同交易形态、同跟踪主题的基金，避免把场内 ETF、场外联接、QDII 直接混成一组。
- 若用户问题本身就在比较不同类型产品，回答里要先说明“不完全可比”，再给出差异说明。
- 净值、份额、场内行情属于不同维度，不能用单一指标代替整体判断。
- 如果工具只拿到一只基金的有效数据，不能输出“二选一”结论。
