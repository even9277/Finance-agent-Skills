# 输出口径

- 结论必须对应已拿到的工具结果，不要把常识当成当期证据。
- 用户画像只影响表达顺序和风险提示，不替代事实依据。
- 若证据不足，优先降级为“给出已知差异 + 提示补充基金名称/稍后重试”。
- 回答中要尽量标注数据来源为 Tushare，以及能识别出的数据日期。
