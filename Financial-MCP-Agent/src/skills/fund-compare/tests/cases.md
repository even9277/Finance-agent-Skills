# fund-compare 回归问法样例

- 对比华安黄金ETF和博时黄金ETF，哪个更适合我这种偏保守投资者？
- 易方达沪深300ETF和华泰柏瑞沪深300ETF有什么区别？
- 帮我比较纳指ETF、标普500ETF和黄金ETF，先讲风险再给结论。
- 我想在短线里二选一，创业板ETF和科创50ETF哪个更合适？
- 帮我看一下华安黄金ETF。应缺少第二个比较对象，先追问或转单基金分析。
- 对比华安黄金ETF和某黄金基金。若同名歧义过多，应说明候选不稳定。
- 黄金ETF和纳指QDII哪个更适合长期配置？允许跨类比较配置属性，但不能输出强收益排序。
- 只有基础信息没有净值/份额/行情时，只能说明产品差异，不做强排序。
