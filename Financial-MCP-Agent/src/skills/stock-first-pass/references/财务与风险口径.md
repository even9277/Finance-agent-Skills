# 财务与风险口径

- 盈利能力结合 ROE、毛利率、净利率和扣非口径，不用单一营收增速代替质量判断。
- 成长性同时观察收入、利润和现金流；利润增长但经营现金流持续偏弱时标记质量风险。
- 资产负债结构结合负债率、流动性、应收、存货和现金流，不凭单张报表下完整结论。
- 允许表达“值得继续跟踪”或“当前证据支持谨慎观察”，禁止确定上涨、无风险等承诺。
