# 财务与风险口径

## 财务指标解释

- 盈利能力优先看 ROE、毛利率、净利率和扣非口径，避免只用营收增速判断公司质量。
- 成长性要同时看收入、利润和现金流，不把单期利润高增长直接解释成长期趋势。
- 偿债和资产质量要结合资产负债率、流动性、应收应付和存货变化，避免只看利润表。
- 现金流质量要重点看经营现金流和净利润是否长期背离。

## 三表质量判断

- 利润表说明“赚了多少”，资产负债表说明“资产和负债结构是否健康”，现金流量表说明“利润有没有变成现金”。
- 如果利润增长但经营现金流持续偏弱，应标记为质量风险。
- 如果负债扩张明显快于收入或利润，应标记为杠杆风险。
- 如果只有某一张表可用，只能做局部观察，不能输出完整基本面判断。

## 非投资建议边界

- 可以说“更适合继续跟踪”“当前证据支持谨慎观察”“需要等待财报或价格确认”。
- 不要说“必买”“一定上涨”“无风险”“确定见底”。
- 用户问“能买吗”时，优先转换成“当前证据是否支持纳入观察或分批跟踪”。
