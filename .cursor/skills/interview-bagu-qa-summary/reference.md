# 八股面试问题总结 — 参考模板

与 [SKILL.md](SKILL.md) 配套。

## 产出路径

- **不写死** `interview-doc/mysql/面试问题.md`。
- 用户在**首次调用**或本会话第一次产出时**指明路径**；或「写到当前打开文件」。
- 项目内可有多个专题文件，例如：`interview-doc/redis/面试问题.md`、`interview-doc/mq/面试问题.md`。

## 按技术栈选贯穿案例（速查）

| 技术栈 | 贯穿对象示例 |
|--------|----------------|
| MySQL | `user` / `user_account` |
| Redis | `user:session:{id}`、`cache:profile:{id}` |
| 消息队列 | `order.paid` 事件、同一 consumer group |
| 向量库 | 固定文档集 + 同一查询向量 |
| 网络 | 一次完整请求链路 |
| 操作系统 | 同一进程/多线程故事 |

## 产出结构示例

```markdown
### N. 面试主题？

**N.1 子问题一**

---

**回答：**

**要点一句话：** …

**实战场景：** …

**问题定义：** …

**预备：** （可选）…

**八股理解：**  
Step 1：…  
Step 2：…

**代码示例：** （按需，与贯穿对象一致）

**开发心得 / 要点：** …

**口述提示：** 面试时先一句话答…，再展开…（默认必有；用户关闭本 skill 口述时省略）
```

## 叙事链路速查

要点一句话 → 场景 → 问题 → 八股(step) → 代码 → 心得 → **口述提示**。

## 与「要求.md」对齐时

- 若目录下 `要求.md` 与 skill 冲突：**以用户当轮对话为准**；其次看 `要求.md`。
- `要求.md` 可约定「关闭口述提示」或固定产出路径（仅该子项目有效）。

## 禁止项（回答区）

- `####` 及以下标题。
- 无 **要点一句话** 或无 **口述提示**（除非本任务已声明关闭口述）。
- 纯术语罗列、无场景与心得。

## 协作口令

「继续 + 八股片段 +（可选）写入路径」→ 按 SKILL 执行。
