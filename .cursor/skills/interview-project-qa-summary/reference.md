# 项目 / 实习面试问题总结 — 参考

与 [SKILL.md](SKILL.md) 配套。

## 与「八股」skill 的分工

| 维度 | `interview-bagu-qa-summary` | `interview-project-qa-summary`（本 skill） |
|------|-----------------------------|---------------------------------------------|
| 素材 | 八股文段落、通用后端考点 | 简历项目点 + **本仓库代码/配置** |
| 证据 | 贯穿案例 + 通用代码示例 | **文件路径 + 行号**（默认不贴代码） |
| 叙事 | 场景→原理→代码→口述提示 | 场景→边界→0→1/数据流→**工程取舍**→**上线/突发**→大厂对照→**简历一致性**→**口述提示** |
| 口述提示 | 默认开启（可关） | **默认每题末尾必有**（用户/`要求.md` 关闭时省略） |
| 一致性 | 单题内自洽 | **代码 + 简历 + 同文档其他题** 三角对齐，术语与口径前后统一 |

## 产出结构示例（单题）

```markdown
### N、面试官可能问的一句话题目？

**这道题问的是：** …（划清与相邻概念的边界）

**对应代码位置（仅列名称与行号，不贴代码）：**  
- …：`path/to/file.py` L10-L25  
- …：`other/module.py` L100-L120  

**Step1 …**  
…

**Step2 …**  
…

**Step3 …**  
…

**与简历&现状的一致性说明。** …（已实现 / 未实现 / 建议补；与简历表述是否一致）

**口述提示：** 面试时先用一句话答…，再按 Step 展开…（勿重复粘贴上文；用户关闭口述时可整段省略）
```

## 阅读阶段速查

1. **产出路径 + 简历路径**（用户当轮指明；未给则问）、编号、是否贴代码  
2. 同文档 **开篇总述 + 与本题相关的已有 `###` 题**（术语、业务设定、结论口径）  
3. 简历中的相关 bullet（用户给出的简历文件）  
4. 仓库搜索 → 路径+行号  
5. 追加时读产出文件尾部 80～120 行接编号  

## 分析策略速查

- **三角对齐**：代码锚点（事实）+ 简历措辞 + 同文件其他题既定说法；冲突以代码为准并在末段说明。  
- **先证据后发挥**：行号在前，叙述在后。  
- **Step + 加粗**，不用 `####`；题头 `、` / `.` **与同文件已有题一致**。  
- **括号解释**专业词。  
- **大厂泛指** + **本项目对照**（一致/简化/缺失）。  
- **差异收口**到「与简历&现状的一致性说明」，便于改简历或改代码。  
- **口述提示**：一句开场顺序 + 展开线索，不堆全文。  

## 禁止项（默认）

- 臆造不存在的文件或 API。  
- 大段粘贴源码（除非用户明确要求）。  
- 回答区使用 `####` 及以下 Markdown 标题。  
- 虚构具体公司名或无法验证的「我们厂都这样做」。  
- 与同文档前几题 **业务设定/术语/已实现口径** 矛盾且不说明（若必须改口，在一致性段写清）。  
- 省略 **口述提示**（除非用户或 `要求.md` 已关闭）。
